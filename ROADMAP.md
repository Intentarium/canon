# Intentarium roadmap

This roadmap describes sequencing, not a promise of dates or autonomous execution.

## Current foundation

- A public, versioned Canon with governance, schemas, twelve founding hypotheses, and deterministic projections.
- A static human and machine read plane built from a pinned Canon commit.
- A local-first Agency Map Workbench that exports JSON and Markdown without sending field contents to Intentarium.

## Next: Evidence Loop v0.1

Define and pilot public-safe field reports that preserve supportive, mixed, neutral, and contradictory outcomes. Reports remain human-reviewed Canon objects; synthetic examples never count as evidence, and pattern maturity never changes automatically.

## Then: Guide 01 and founding pilots

Publish a practical first guide and run a small set of reviewed pilots using **enterprise technology modernization** as the initial learning wedge. This is a broad problem domain, not a reference to or endorsement by any employer, customer, vendor, or partner. Pilot material enters the Canon only as deliberately sanitized, public-safe abstraction with explicit permission.

## Later: a bounded System Clinic

Consider interactive reasoning only after the method and evidence loop demonstrate real utility and the platform has explicit privacy boundaries, abuse controls, cost ceilings, evaluation coverage, provenance, and human-visible authorization. The Clinic must consume governed Canon objects; it must not silently create or promote them.

## Not on the critical path

Accounts, server-side storage of private Agency Maps, autonomous publication, automatic maturity promotion, and opaque model memory are not prerequisites for learning from the first users.
